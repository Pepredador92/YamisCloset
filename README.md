# Yamis Closet

Tienda en línea de moda femenina. Este repositorio contiene la aplicación y la configuración de desarrollo local de Yamis Closet.

## Desarrollo local

La configuración de contenedores de desarrollo está en `docker-compose.yml`. Los valores locales de conexión y servicios se guardan en `.env`, que no se versiona. Copia `.env.example` a `.env` solo si necesitas preparar una instalación nueva.

La tienda usa Laravel y conserva los avisos de licencia incluidos en el código fuente. Los nombres técnicos de dependencias, rutas y comandos del proyecto base se mantienen para que el sistema y sus paquetes sigan funcionando.
